SpaceLens v0.1.1 is an unsigned packaging patch. Product behavior is
unchanged from v0.1.0.

## Why this release

The primary Windows archive now includes both interfaces of SpaceLens:
the desktop GUI and the read-only CLI. One normal install is enough.

The v0.1.0 GUI-only zip remains published and immutable. It is not
replaced. There is no new GUI-only zip for v0.1.1.

## Highlights

- Unified portable archive: `spacelens-gui.exe` and `spacelens.exe` in
  the same folder as the Qt 6.8.3 runtime
- Optional CLI-only archive for headless/script use
- CLI still reports `filesystem_mutation: false`
- Same MIT project license and Qt LGPL corresponding-source offer

Both expose the `spacelens` command.

## Requirements

- Windows 10/11 x64
- [Microsoft Visual C++ Redistributable (x64)](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)
- Qt 6.8.3 runtime is bundled in the unified archive only
- Binaries are unsigned. Verify the zip hashes before use.

## Safety

The CLI cannot delete, recycle, restore, move, or declare locations.
Recycle Bin maintenance stays in the GUI and requires explicit human
authorization. SpaceLens does not write the NTFS USN journal.
