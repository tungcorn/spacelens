# SpaceLens v0.1.4

Indexed intelligence is now significantly more exact, scalable, and honest.

v0.1.3 stays published and immutable. This is a new tag, new assets, and
`@tungcorn/spacelens@0.1.4`.

## What changed

Storage intelligence ranks developer, build, and cache opportunities
with sibling and project context instead of leaf-name-only guesses.

Indexed `opportunities` now returns the exact public top-N across the
whole matching published index. Filters run before the result limit.
Overlap-aware `unique_review_bytes` is exact for that published
snapshot — not a 50,000-row estimate, and not guaranteed freed disk
space.

Indexed results report published-snapshot age. Optional
`--max-index-age-seconds` / MCP `max_index_age_seconds` fails closed
when the snapshot is too old or its age is unknown. There is no
default age policy, no automatic refresh, and no hidden live fallback.

`spacelens index list --json` is the machine-readable catalog of
published roots. An agent can discover indexes before choosing one.

## Agent workflow

```text
spacelens index list --json
        ↓
choose a ready published root
        ↓
overview --from-index
        ↓
opportunities --from-index
        ↓
query
        ↓
duplicates
```

Exact indexed results are exact for the published snapshot. They are
not guaranteed live filesystem truth.

## Safety

CLI and MCP analysis do not mutate analyzed user files.
`filesystem_mutation: false` and `read_only: true`. Human-authorized
Recycle Bin maintenance remains GUI-only.

**AI recommendation is not filesystem permission.**

MCP still exposes six read-only tools. This release does not add
delete, recycle, restore, move, or index-refresh tools.
