# SpaceLens v0.1.0

SpaceLens is native C++ storage intelligence for Windows: a desktop analyzer for humans, and a deterministic read-only CLI for scripts and external AI agents.

This is the first public **prerelease**. Binaries are **unsigned**. It is not a stable production release.

## Highlights

- Native C++20 filesystem scanning with logical-size aggregation
- Persistent SQLite index under AppData, with optional incremental NTFS USN refresh
- Indexed search, filters, Storage Overview, and an interactive treemap
- Durable Cleanup Review for planning only
- Verified exact-duplicate detection (same size is not a duplicate)
- User-declared Ordinary locations (classification only — not safe to delete)
- GUI Recycle Bin maintenance after explicit human authorization
- Read-only JSON CLI for humans, scripts, and AI agents (`filesystem_mutation: false`)

## Requirements

- Windows 10/11 x64
- [Microsoft Visual C++ Redistributable (x64)](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)
- The GUI zip already includes the required Qt 6.8.3 shared runtime
- Binaries are currently unsigned

## Safety

- The CLI cannot delete, recycle, move, restore, or write safety declarations
- `spacelens capabilities --json` reports `filesystem_mutation: false`
- GUI Recycle Bin maintenance requires an explicit human confirmation
- No permanent delete, directory recycle, or Recycle Bin Restore in v0.1.0
- SpaceLens does not modify the NTFS USN journal
