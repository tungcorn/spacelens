# SpaceLens v0.1.3

SpaceLens is now an AI-ready native storage intelligence engine.

```text
                 spacelens_core
                /      |       \
               /       |        \
      spacelens     spacelens-mcp    SpaceLens (GUI)
      CLI           stdio MCP        human inspection
      scripts       AI harnesses     + Recycle Bin
```

SpaceLens provides deterministic storage evidence. External AI performs
reasoning. **AI recommendation is not filesystem permission.**

v0.1.2 stays published and immutable. This is a new tag, new assets, and
`@tungcorn/spacelens@0.1.3`.

## AI-ready storage intelligence

The CLI and MCP adapter share one core analysis path:

```text
overview  →  opportunities  →  query / drill-down  →  duplicates
```

`overview` and `opportunities` compose a live scan or a published index
into a bounded storage summary and ranked review opportunities. Indexed
`query --under` is drill-down only: it never live-scans and never
refreshes the index. Reports say whether evidence is live or indexed.

There is no embedded model.

## Native MCP server

`spacelens-mcp.exe` is a native stdio MCP server over `spacelens_core`.
It is not a CLI wrapper. Six read-only tools:

- `storage_capabilities`
- `storage_overview`
- `storage_opportunities`
- `storage_query`
- `storage_duplicates`
- `storage_index_status`

It ships in the complete archive, the headless archive, and the npm
package (`spacelens-mcp`). stdout is protocol only. This release does
not claim compatibility with any particular MCP host beyond the
verified stdio contract.

## Faster duplicate detection

Repeated analysis of unchanged files can reuse a previously verified
SHA-256 digest from `%LOCALAPPDATA%\SpaceLens\hash-cache.db`. Path is
never the cache key. Reuse requires FileId128 + size + ChangeTime +
FileUsn. A false cache hit is a defect; insufficient evidence hashes
again. Unchanged repeat runs are faster, not instant.

## GUI polish

Live Scan and Indexed are segmented workspaces with clearer tables,
inspectors, and status. Cleanup Review confirmation remains **Move
eligible files to Recycle Bin**.

## Safety

CLI and MCP analysis do not mutate analyzed user files.
`filesystem_mutation: false` and `read_only: true`. Human-authorized
Recycle Bin maintenance remains GUI-only.

SpaceLens-owned AppData may contain indexes, state migrations, and a
derived hash cache. That is implementation state, not a scanned-root
write.
